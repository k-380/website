拡散方程式の時間発展比較

まったく同じ初期分布（区間内総量を1に正規化）から、境界なし・反射壁・吸収壁・端→中心ジャンプの時間発展を比較します。 区間は反射壁・吸収壁で 0 ≤ x ≤ L、境界なしは同じ表示範囲を切り出して見せています。

1. 境界なし

無限空間。ガウス分布のまま幅が広がる。
表示範囲内質量 - 最大値 -

2. 反射壁

Neumann境界条件：∂u/∂x = 0。総量を保存し、最終的に一様。
総量（保存） - 最大値 -

3. 吸収壁

Dirichlet境界条件：u = 0。壁から流出し、最終的に消滅。
生存質量 - 最大値 -

4. 端 → 中心ジャンプ

端で吸収された質量を、その瞬間に x = L/2 へ再注入。総量保存。
総量（保存） - 最大値 -
見どころ： 4条件は t=0 で同一の分布から出発します。縦軸は全グラフで 0〜9 に固定しています。分布が壁へ到達すると、反射壁では折り返され、吸収壁では失われ、端→中心ジャンプでは失われた質量が中心へ戻されます。長時間では、反射壁は一様分布へ、吸収壁はゼロへ、中心ジャンプ条件は中心が高い三角形状の定常分布へ向かいます。
