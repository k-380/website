WEB SENSOR API SUPPORT

Web版HUD。ブラウザが公開しているセンサーだけ取得できます。気圧計・近接・端末温度・指紋などは、 Pixel 7a本体にハードウェアが存在しても通常のWeb APIから直接取得できない場合があります。 Generic Sensor APIはHTTPSなどのSecure Contextでの利用が前提です。
