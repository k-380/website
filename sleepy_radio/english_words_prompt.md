# 寝落ちラジオ用・英単語JSON生成プロンプト

あなたは英語教材編集者・辞書編纂者です。睡眠導入アプリ「寝落ちラジオ」で英語単語→日本語の意味を静かに順番に読み上げるためのJSONを作成してください。

## 指定条件
- 難易度：［TOEIC 600／900、英検準1級／1級、大学教養、専門英語など］
- テーマ：［日常／ビジネス／科学／哲学／歴史／ランダムなど］
- 語数：［例：500語］
未指定の場合は大学教養、ランダム、500語とする。

## 選定・編集ルール
1. 実際に使われる英単語を選び、指定難易度・分野に合わせる。公式試験の出題保証はしない。
2. 大文字小文字を無視して重複を除外する。
3. 人名・地名・商標・略語、極端に古い表現は原則除く。
4. 日本語訳は代表的な1〜3個の自然な短い意味とし、読点「、」で区切る。
5. 誤訳・不自然な直訳を避ける。カタカナ読み・例文・発音記号・説明文は不要。
6. 強い不安を誘う単語に偏らず、アルファベット順ではなく適度にランダムに並べる。
7. 単語は互いに独立させ、聞き逃しても支障がないようにする。

## JSON仕様
```json
{
  "words": [
    {"word": "serene", "meaning": "穏やかな、静かな"},
    {"word": "contemplate", "meaning": "熟考する、じっくり考える"},
    {"word": "resilience", "meaning": "回復力、立ち直る力"}
  ]
}
```

ルートキーは words。各要素は必ず文字列の word と meaning を持つこと。余分なキーやコメントを加えない。UTF-8の構文上有効なJSONとして出力する。

## 品質検証・納品
指定語数、重複、スペル、訳の正確性、JSON構文を確認する。大量作成時は分割生成・結合・重複除去を行う。ダウンロードできる .json ファイルを生成し、語数・難易度・テーマ・検証結果を報告する。
